# Compliance Audit Checklist

Interactive compliance audit tool for Kenya DPA, banking sector, and telecom requirements.

## Features

- Interactive compliance checklist
- Kenya DPA alignment
- Banking and telecom-specific requirements
- Audit evidence tracking
- Compliance reporting

## Compliance Standards Covered

- **Kenya DPA** - Data Protection Act requirements
- **CBK Guidelines** - Central Bank of Kenya banking guidelines
- **CII Mandate** - Critical Information Infrastructure security
- **ISO 27001** - Information security management

## Checklist Categories

1. **Data Protection** - DPA compliance
2. **Access Control** - Who can access what
3. **Incident Response** - Breach handling procedures
4. **Encryption** - Data protection in transit/at rest
5. **Audit Trail** - Logging and monitoring
6. **Policies** - Security policies and documentation
7. **Training** - Staff security awareness
8. **Third-party Management** - Vendor security

## Usage

```bash
pip install -r requirements.txt
python app.py
# Visit http://localhost:5000
```

## Architecture

- **Backend:** Flask
- **Database:** SQLite
- **Frontend:** HTML/CSS/JavaScript
- **Export:** PDF compliance reports
